# 📂 Documentación del Proyecto Victus Residencias

Este repositorio contiene la documentación completa del proyecto **Victus Residencias**, incluyendo diseño funcional, modelado de dominio, muestreo de datos y preparación de software.  
El proyecto fue desarrollado como parte de un esfuerzo colaborativo para crear un sistema de gestión de reservas y administración en conjuntos residenciales.

## 📝 Descripción del Proyecto

Victus Residencias es un sistema integral para la **gestión de conjuntos residenciales**, que permite administrar zonas comunes, viviendas, residentes y reservas.  
El desarrollo se ha dividido en tres fases principales: **Diseño, Backend y Frontend**.

En este repositorio se encuentra todo el material de diseño y análisis, incluyendo:
- **Event Storming** por módulo (Agendas, Conjuntos Residenciales, Reservas, Residentes).
- **Modelos de dominio anémicos y enriquecidos**.
- **Muestreo de datos** para validación y pruebas.
- **Diagramas** en formato Draw.io y PNG.
- **Casos de uso** y **consultas SQL** para creación de base de datos.
- Documentos de referencia y enlaces a herramientas externas.
